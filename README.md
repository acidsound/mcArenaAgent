# AEGIS — The Last Command

A browser-based 3D missile-defense arcade game built with Three.js and Vite. Defend six cities across escalating attack waves, direct three interceptor batteries, and enter immersive WebXR mode on supported headsets.

## Run locally

```sh
npm install
npm run dev
```

Open the Vite URL in a modern browser. For WebXR, use a secure context (HTTPS or localhost) and a compatible headset/browser.

## Controls

- **Mouse / touch:** move the reticle and click/tap to launch an interceptor.
- **Battery cards / 1, 2, 3:** select a launch battery. With no manual selection, the closest battery is chosen automatically.
- **Space:** fire at the current aim point.
- **P / Escape:** pause or resume.
- **M:** toggle sound effects.
- **F:** toggle fullscreen.
- **WebXR:** enter immersive mode, point a controller, and press its trigger to fire.
